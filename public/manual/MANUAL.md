# OH! Packing 사용 매뉴얼

국내·중국·인도 패킹리스트를 상품 코드와 자동으로 매칭하고, 수량이 맞는지 검증해주는 도구입니다. 이 문서 하나로 업로드부터 최종 다운로드까지 혼자 따라 할 수 있게 정리했습니다.

**접속 주소**: https://india-packing-web-cddc.vercel.app

---

## 이 도구가 하는 일

공장/수입처에서 받은 패킹리스트(엑셀·PDF·사진)를 올리면, 우리 쪽 상품 DB와 자동으로 대조해서 상품코드를 붙여주고 수량이 맞는지 확인해줍니다. 왼쪽 사이드바에서 국내/중국/인도 중 작업할 리스트 종류를 먼저 선택하세요.

![기본 화면 — 왼쪽에서 리스트 종류를 고르고, 가운데 업로드 영역에 파일을 올립니다.](/manual/01-home.png)

---

## 공통 작업 흐름 (5단계)

국내·중국·인도 어느 탭이든 기본 흐름은 같습니다.

### 1. 파일 업로드
PDF, 엑셀(xls/xlsx), 또는 고해상도 이미지를 업로드 영역에 끌어다 놓거나 클릭해서 선택합니다.

### 2. 동기화 / 변환
"○○ 데이터 동기화" (또는 "변환") 버튼을 누르면 상품 DB와 자동으로 매칭됩니다. 파일 크기에 따라 몇 초에서 몇십 초 걸릴 수 있습니다.

### 3. 결과 확인
상단에 "원본 수량"과 "매칭 수량"이 나란히 뜹니다. 두 숫자가 같으면 초록색 "수량 일치"가 표시됩니다. 다르면 목록에서 미매칭/중복확인 항목을 찾아 수동으로 교정해야 합니다. 아래 [결과 화면 읽는 법](#결과-화면-읽는-법)에서 점/아이콘 의미를 확인하세요.

### 4. 수동 교정
확인이 필요한 행을 클릭하면 "수동 매칭 교정" 창이 뜹니다. 상품명이나 코드를 검색해서 정확한 상품을 클릭하면 바로 반영되고, 같은 스타일의 다른 사이즈·색상 행들도 자동으로 같이 교정됩니다.

이때 고른 매칭은 학습되어서, 다음에 같은 표기의 상품이 나오면 자동으로 맞게 잡힙니다.

![행을 클릭하면 뜨는 수동 매칭 교정 창. 상품명이나 코드로 검색해 정확한 상품을 고릅니다.](/manual/03-manual-match-modal.png)

### 5. 서명 추가 & 다운로드
"서명 추가"를 누르면 이름을 입력하는 창이 뜹니다. 한 번 입력하면 다음부터 자동으로 기억됩니다. 확인을 누르면 결과 화면(또는 업로드한 이미지) 우측 하단에 도장처럼 이름이 찍힌 이미지가 다운로드됩니다.

최종 결과는 "매칭 엑셀 다운로드"로 받습니다.

![서명 추가 버튼을 누르면 뜨는 이름 입력 창. 기본값은 마지막에 사용한 이름입니다.](/manual/05-signature-modal.png)

## 결과 화면 읽는 법

동기화가 끝나면 나오는 목록의 점·아이콘이 각각 무슨 뜻인지 정리했습니다.

![중국 패킹리스트 동기화 결과 화면 예시. 상단에 원본/매칭 수량과 일치 여부가 뜹니다.](/manual/02-china-synced.png)

| 표시 | 의미 |
| --- | --- |
| 🟢 초록 점 | 상품코드·상품명·색상·사이즈가 DB와 전부 정확히 일치 확인됨. 그대로 두면 됩니다. |
| 🔴 빨간 점 | 매칭은 됐지만 100% 확실하진 않음(사이즈·색상 정보가 부족한 경우 등). 한 번 확인해보는 걸 권장합니다. |
| ⚠️ 미매칭 / 중복확인 | 자동으로 상품을 찾지 못했거나(미매칭), 후보가 여러 개라 하나로 확정하지 못한 경우(중복확인). 반드시 행을 클릭해서 수동으로 교정해야 합니다. |

> **"수량 일치"인데 왜 빨간 표시가 남아있죠?**
> 수량 일치는 전체 합계만 맞는지 보는 겁니다. 개별 상품이 서로 다른 코드로 잘못 매칭돼도 합계가 우연히 맞을 수 있으니, 목록의 점·아이콘은 별도로 확인해주세요.

## 중국 전용 — 파레트 라벨 출력

박스 번호를 인식해서 파레트(운반대) 단위로 라벨을 자동으로 만들어줍니다.

| 카테고리 | 박스/파레트 |
| --- | --- |
| 신발 | 16박스 |
| 의류 | 14박스 |
| 부자재 | 14박스 |

**알아두면 좋은 규칙**

- 박스 번호 순서대로 꽉 채워서 나누고, 맨 마지막 파레트에만 남는 박스가 있습니다 (예: 16, 16, 16 ... 마지막만 3박스).
- 신발/의류 어느 키워드에도 안 걸리는 상품은 "부자재" 파레트로 자동 분류됩니다.
- 한 박스 안에 서로 다른 카테고리 상품(예: 원피스+우비)이 같이 들어있으면, 박스 안에서 먼저 나오는 상품 기준으로 카테고리가 정해지고 라벨에는 "상품A/상품B(혼합)"처럼 표시됩니다.
- "파레트 라벨 출력" 버튼을 누르면 새 창에 인쇄용 라벨이 뜨고, 자동으로 인쇄 대화상자가 열립니다.

![파레트 라벨 출력 예시. 파레트 번호, 박스 범위, 대표 상품명, 박스 수가 큼직하게 표시됩니다.](/manual/06-pallet-print.png)

## 중국 전용 — 분류 키워드 설정

상품이 신발/의류/부자재 중 어디로 분류되는지는 상품명에 포함된 키워드로 판단합니다. 결과 화면 위쪽 톱니바퀴(⚙) 아이콘을 누르면 직접 키워드를 추가·삭제할 수 있습니다.

![분류 키워드 설정 창. 태그를 클릭해 지우거나, 아래 입력창에서 새 키워드를 추가할 수 있습니다.](/manual/04-classification-settings.png)

> **판단 순서**
> 신발 키워드가 걸리면 무조건 신발로 분류됩니다(의류보다 우선). 어느 쪽에도 안 걸리면 부자재로 분류됩니다. 키워드는 상품명의 "카테고리-구체적품명" 중 앞부분(카테고리)에서 먼저 확인합니다 — 예를 들어 "발레복-레인보우리본"은 "발레복"이 키워드에 있으면 의류로 잡힙니다.

> **키워드는 너무 짧게 넣지 마세요**
> 짧은 키워드는 다른 단어와 우연히 겹칠 수 있습니다. 예를 들어 "레인"을 넣으면 색상명 "레인보우"에도 걸려서 엉뚱하게 분류될 수 있어요. "레인" 대신 "레인코트"처럼 구체적인 단어를 추천합니다.

## 인도 전용 — 세트 상품 수량 자동 절반 처리

인도 패킹리스트는 "세트"(상의+하의 세트) 상품일 때, 상의 수량과 하의 수량을 각각 세어 합친 숫자가 한 줄에 적히는 경우가 있습니다.

![매칭된 상품명에 "세트"가 포함되면 QTY FLOW 열에 원래 수량(취소선) → 보정된 절반 수량이 함께 표시됩니다.](/manual/07-india-synced.png)

> **자동으로 처리되니 따로 할 일은 없습니다**
> 매칭된 상품명에 "세트"라는 글자만 포함되면 자동으로 수량이 절반으로 계산됩니다. 원본/매칭 수량 배너도 보정된 값 기준으로 항상 일치하게 표시되니, 평소처럼 확인만 하면 됩니다. 이 보정은 인도 패킹리스트에만 적용되고, 중국·국내에는 영향이 없습니다.

## 국내 전용 — 모바일에서 사진으로 업로드

매장이나 창고에서 휴대폰으로 패킹리스트 사진을 찍어 바로 올리고, 사무실 PC에서 불러와 작업할 수 있습니다.

1. 휴대폰으로 사이트 주소에 접속하면 자동으로 모바일 촬영 화면으로 연결됩니다.
2. 사진을 찍고 패킹리스트 이름을 입력한 뒤 업로드합니다.
3. PC의 국내 패킹리스트 화면에 자동으로 대기열이 뜹니다(약 15초마다 새로고침).
4. PC에서 대기열의 항목을 선택하면 그 사진이 바로 불러와집니다.

## 문제 해결 FAQ

**"박스 정보가 부족하여 파레트를 생성할 수 없습니다"라고 떠요.**
업로드한 엑셀 파일에 박스 번호 컬럼이 없거나, 박스 번호가 하나도 인식되지 않은 경우입니다. 원본 파일의 박스번호 컬럼 형식이 평소와 다르지 않은지 먼저 확인해보세요. 그래도 해결되지 않으면 파일을 공유해주시면 원인을 확인해드립니다.

**"수량 일치"인데 목록엔 빨간 표시가 남아있어요.**
"수량 일치"는 전체 합계만 맞는지 확인하는 겁니다. 개별 상품이 서로 다른 코드로 잘못 매칭돼도 합계가 우연히 맞을 수 있어서, 목록의 빨간 점이나 미매칭·중복확인 표시는 별도로 확인해야 합니다.

**"중복확인"이 계속 뜨는 상품이 있어요.**
패킹리스트에 적힌 상품명이 너무 간단해서(색상·사이즈 정보 없이 별명만 있는 경우 등) 실제로 다른 여러 상품과 동시에 이름이 겹치는 상황입니다. 한 번 수동으로 정확한 상품을 골라주면 학습되어, 다음부터는 같은 표기의 상품이 자동으로 맞게 잡힙니다.

**서명이 이상한 곳에 찍히거나 안 눌러져요.**
서명은 항상 화면(또는 이미지) 우측 하단에 큼직한 테두리와 함께 찍힙니다. PDF·엑셀 파일은 화면에 표시된 변환 결과를 그대로 캡쳐해서 그 위에 서명을 찍기 때문에, 변환(동기화) 결과가 먼저 화면에 나와 있어야 서명 추가 버튼을 누를 수 있습니다.

**같은 상품/색상/사이즈인데 결과 목록에 두 줄로 나와요.**
서로 다른 박스에 나뉘어 담긴 경우 화면에서는 수량을 합쳐 한 줄로 보여주고 "(N박스 합산)"이라고 표시합니다. 그래도 두 줄로 보인다면 실제로는 상품코드나 색상·사이즈 중 하나가 미묘하게 다른 경우이니, 각 행을 클릭해서 내용을 확인해보세요.
